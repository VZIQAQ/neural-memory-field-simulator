# 神经记忆场模拟器 · V5.4（弹性空间版）

一个用于探索 AI 记忆检索机制的交互式模拟器。

## 这是什么

这是一个在浏览器中运行的记忆场模拟器。它将对话记忆建模为图结构，通过热核扩散和链路传播来模拟记忆的激活与检索。主要用来研究：

- 记忆节点密度对检索性能的影响
- 「确定」与「追问」状态的切换机制
- 弹性空间如何解决大规模记忆检索的性能问题

## 核心机制

- **热核扩散**：查询作为热源，在记忆图上扩散能量，激活相关记忆
- **链路传播**：从主峰出发沿突触连接传播，唤醒关联记忆
- **窗口隔离**：当前对话窗口节点不参与检索（已在上下文中）
- **弹性空间**：节点数量增加时，语义空间自动扩展，保持密度恒定
- **Hebbian 塑形**：共激活的节点之间边权重自动增强

## 如何使用

直接用浏览器打开 `记忆模拟器V5.4-弹性空间.html` 即可运行。

1. 点击「新建对话」初始化记忆场
2. 点击「用户输入」模拟一轮对话
3. 观察右侧面板的 T1 值、状态（确定/模糊/追问）、Token 消耗
4. 调节左侧参数观察系统行为变化

## 核心参数说明

| 参数 | 作用 |
|------|------|
| 温层节点总数 | 记忆场中的节点数量 |
| 弹性空间 | 自动根据节点数扩展空间，保持密度恒定 |
| 热核步数 | 信号在图上传播的跳数 |
| 链路深度 | 从主峰向外传播的步数 |
| T1 确定阈值 | >0.75 时系统进入「确定」状态 |

## 实验结论

通过本模拟器，我们发现：

- 固定空间下，节点超过 800 后性能急剧下降
- 弹性空间使 2000 节点成功率从 13.3% 提升到 66.7%
- 节点密度恒定比节点数量更重要

详细实验数据见项目文档。
